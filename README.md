# Un jardín para Mafer

Sitio estático y móvil creado para Mafer. El contenido está centralizado en `dist/story.js`, las fotos públicas están en `dist/media/` y la página se entrega desde `dist/index.html`.

## Ajustes rápidos

- Cambia textos, recuerdos, frases del jardín y galería en `dist/story.js`.
- Cambia la carta directamente en `dist/index.html` dentro de `#letter-modal`.
- Para usar otras fotos, reemplázalas en `dist/media/` y actualiza sus nombres y textos alternativos en `dist/story.js`.
- El jardín conserva las flores solamente durante la sesión del navegador.

La página usa `noindex,nofollow` y no carga tipografías, analítica ni recursos de terceros.
